# Clon de Google

Este proyecto es una réplica simple de la interfaz de búsqueda de Google, desarrollado como ejercicio de práctica en HTML, CSS y JavaScript.

## 🧠 ¿Qué incluye?

- Página principal con el logo de Google y barra de búsqueda.
- Al enviar una búsqueda, redirige a una página de resultados.
- Los términos de búsqueda se muestran dinámicamente usando JavaScript.

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)

## 📁 Estructura del proyecto

clon_google/
├── index.html
├── resultados.html
├── script.js
├── resultados.js
└── styles.css
